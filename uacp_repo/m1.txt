sdk agents
-----------
sequenceDiagram
    autonumber
    participant CI          as Dev - SDK
    participant Vault       as Key Vault
    participant EAR         as Enterprise Agent Registry
    participant Gateway     as U-ACP Gateway
    participant AgentA      as MembershipAgent  (SDK)
    participant AgentB      as BrokerCompAgent (SDK)

    %% On-boarding
    CI ->> Vault: create RSA keypair
    Vault -->> CI: private.pem + JWKS
    CI ->> EAR: POST /onboard {manifest, jwks_uri}
    EAR -->> CI: 200 OK

    %% Runtime call
    AgentA ->> Gateway: JSON-RPC (JWT, nonce, scope=tool:get_comp_statement)
    Gateway ->> Gateway: verify sig • scope • nonce • allow-list
    Gateway ->> AgentB: forward
    AgentB -->> Gateway: response (JWT)
    Gateway -->> AgentA: relay


non sdk
------
sequenceDiagram
    autonumber
    participant Proxy    as Internal U-ACP Proxy
    participant Legacy   as Non-SDK Agent
    participant EAR      as Registry
    participant Gateway  as U-ACP Gateway
    participant Caller   as MembershipAgent (SDK)

    %% Proxy on-boarding
    Proxy ->> EAR: POST /onboard {manifest, JWKS}

    %% Runtime
    Caller ->> Gateway: U-ACP request
    Gateway ->> Proxy: forward (verified)
    Proxy ->> Legacy: REST /internalCall
    Legacy -->> Proxy: 200 OK
    Proxy -->> Gateway: U-ACP response
    Gateway -->> Caller: relay



vendor
-----
sequenceDiagram
    autonumber
    participant VendorProxy  as "Vendor U-ACP Proxy\n(on-boards like any agent)"
    participant VendorSvc    as "Partner’s Existing Service"
    participant Gateway      as "U-ACP Gateway"
    participant Caller       as "MembershipAgent (SDK)"
    participant EAR          as "Registry"

    %% On-board once
    VendorProxy ->> EAR: POST /onboard {manifest, JWKS}

    %% Live traffic
    Caller ->> Gateway: signed JSON-RPC
    Gateway ->> VendorProxy: forward
    VendorProxy ->> VendorSvc: REST /whatever
    VendorSvc -->> VendorProxy: 200 OK
    VendorProxy -->> Gateway: signed response
    Gateway -->> Caller: relay
